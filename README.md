🎯 Number Guessing Game – Java

A console-based Number Guessing Game developed using Core Java. The player selects a difficulty level and tries to guess a randomly generated number with helpful hints.

🚀 Features

🎲 Random number generation
🎮 Three difficulty levels
Easy: 1–50
Medium: 1–100
Hard: 1–500
🔢 Attempt tracking
💡 Higher/Lower hints
✅ Input validation
🔄 Play Again option
⭐ Performance evaluation
🧩 Modular programming using Java methods
🛠️ Technologies Used

Java
Core Java
"Scanner"
"Random"
Loops
Conditional Statements
Methods
Input Validation
▶️ How to Run

Install Java JDK on your computer.
Clone or download this repository.
Open the project in any Java IDE or terminal.
Compile the program:
javac NumberGuessingGame.java

Run the program:
java NumberGuessingGame

🎮 How to Play

Select a difficulty level.
Enter your guessed number.
The game tells you whether your guess is Too High or Too Low.
Continue guessing until you find the correct number.
The game displays your total attempts and performance.
Choose whether you want to play again.
